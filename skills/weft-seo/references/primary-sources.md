# Primary SEO Sources

Use primary, current sources for general SEO claims. Provider data supports the
specific market evidence; it does not replace platform documentation.

- [Google Search Essentials](https://developers.google.com/search/docs/essentials)
  for technical requirements, spam policies, and key practices.
- [Google SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide)
  for crawlable links, useful content, titles, snippets, images, and common
  misconceptions.
- [Google guidance for AI features](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide)
  for AI-search eligibility and the absence of special AI-only requirements.
- [Google structured data introduction](https://developers.google.com/search/docs/appearance/structured-data/intro-structured-data)
  for eligibility, implementation, and visible-content agreement.
- [Web Vitals](https://web.dev/articles/vitals) for user-centered performance
  metrics and measurement context.
- [Schema.org developer documentation](https://schema.org/docs/developers.html)
  for current vocabulary and release information.
- [IndexNow documentation](https://www.indexnow.org/documentation) for the
  supported change-notification protocol and its limits.

Check source dates and current platform documentation when guidance can change.
Do not promise indexing, rich results, rankings, traffic, or inclusion in an AI
answer. Eligibility and valid implementation are not guarantees.
